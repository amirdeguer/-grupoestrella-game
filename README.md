# Grupo Estrella · Flappy Guardia ULTIMATE

Versión móvil/PWA reconstruida desde cero con arte, iconos y animaciones originales.

## Mecánicas
- toque/clic/espacio para volar
- gravedad y salto tipo arcade clásico
- obstáculos con huecos aleatorios
- 1 punto por obstáculo superado
- pantalla PREPARATE
- pausa y reanudar
- GAME OVER
- récord local
- medallas por puntaje
- sonidos de salto, punto, golpe y derrota
- personajes seleccionables
- funcionamiento offline tras la primera carga

## GitHub Pages
1. Crear repositorio.
2. Subir TODO el contenido de esta carpeta a la raíz.
3. Settings → Pages.
4. Deploy from a branch.
5. Branch main / root.
6. Abrir la URL de GitHub Pages.

## iPhone
Safari → Compartir → Agregar a pantalla de inicio.
